# অ্যান্ড্রয়েড APK তৈরি ও ইনস্টলেশন গাইড (Android APK Generation Guide)

**"লাবীবের খেরোখাতা"** অ্যাপটিকে যেকোনো অ্যান্ড্রয়েড ফোনে সরাসরি `.apk` ফাইল হিসেবে ইনস্টল করার জন্য বা গুগল প্লে স্টোরে আপলোড করার জন্য দুটি চমৎকার ও সহজ উপায় রয়েছে:

---

## পদ্ধতি ১: PWABuilder (সবচেয়ে সহজ ও ১-ক্লিক পদ্ধতি - কোনো কোডিং ছাড়া)

এটি মাইক্রোসফটের অফিসিয়াল ও বিশ্বের সবচেয়ে জনপ্রিয় ওপেন-সোর্স টুল যা যেকোনো PWA থেকে স্বয়ংক্রিয়ভাবে সাইনড `.apk` এবং `.aab` ফাইল তৈরি করে দেয়:

1. আপনার সাইটটি লাইভ হলে (যেমন Vercel, Netlify বা নিজস্ব ডোমেইনে) ব্রাউজারে প্রবেশ করুন:
   👉 **[https://www.pwabuilder.com/](https://www.pwabuilder.com/)**
2. ওয়েবসাইটের লিংকটি (যেমন `https://affanlabib.me`) ইনপুট বক্সে দিয়ে **"Start"** চাপুন।
3. সমস্ত টেস্ট সবুজ (Green 100%) আসবে কারণ আমাদের `manifest.webmanifest`, Icons এবং `sw.js` সম্পূর্ণ প্রস্তুত।
4. **"Package for Stores"** বাটনে ক্লিক করুন।
5. **Android** নির্বাচন করে **"Generate Package"** চাপুন।
6. সাথে সাথে একটি জিপ ফাইল ডাউনলোড হবে, যার ভেতরে থাকবে:
   - `app-release.apk` (সরাসরি মোবাইলে বা বন্ধুদের শেয়ার করে ইনস্টল করার জন্য)
   - `app-release-bundle.aab` (গুগল প্লে স্টোরে সরাসরি আপলোড করার ফাইল)

## পদ্ধতি ২: গুগল বাবলর‍্যাপ সিএলআই (Google Bubblewrap CLI - লোকাল বিল্ড)

যদি নিজের কম্পিউটারের টার্মিনাল থেকেই বিল্ড করতে চান:

### ধাপ ১: বাবলর‍্যাপ ইন্সটল
টার্মিনালে লিখুন:
```bash
npm install -g @bubblewrap/cli
```

### ধাপ ২: টিডব্লিউএ প্রজেক্ট ইনিশিয়ালাইজেশন
আমাদের প্রস্তুতকৃত কনফিগারেশন ব্যবহার করে এক ক্লিকে শুরু করুন:
```bash
bubblewrap init --manifest=https://your-domain.com/manifest.webmanifest
```

### ধাপ ৩: সরাসরি APK বিল্ড
```bash
bubblewrap build
```
এটি সরাসরি আপনার প্রজেক্ট ফোল্ডারে `app-release-signed.apk` ফাইল তৈরি করে দেবে!

---

## পদ্ধতি ৩: তাৎক্ষণিক PWA ইনস্টলেশন (মোবাইল ও পিসিতে)

কোনো APK ফাইল ডাউনলোড করার ঝামেলা ছাড়াই:
1. গুগল ক্রোম বা এজ ব্রাউজারে সাইট খুলুন।
2. মেনুবার থেকে **"📲 অ্যাপ নামান"** বোতামে ক্লিক করুন।
3. অথবা ব্রাউজারের থ্রি-ডট মেনু থেকে **"Install app"** / **"Add to Home screen"** চাপুন।
4. অ্যাপটি আপনার ডিভাইসে আলাদা অ্যাপ আইকন সহ ফুলস্ক্রিনে চালু হবে এবং ইন্টারনেট ছাড়াও পড়া যাবে!
